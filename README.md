# Projet Calcul

Programme en C qui demande deux nombres entiers à l'utilisateur et affiche leur somme.

## Compilation

Depuis le dossier du projet :

    gcc main.c -o calcul

Sous Windows, cela produit `calcul.exe`.

## Exécution

    ./calcul

## Exemple

```
saisir la valeur a:5
saisir la valeur b:7
5+7=12
```

- `main.c` : code source du programme
